# Hindi strings authored for the app

Model-authored, short and spoken in style, with no native review yet. Each table lists the English, the Hindi and where it shows.
Counts are written in Devanagari digits in Hindi (as the dates are). Words that come from the core lookups (`HindiLabels`,
`HindiDate`, `HindiUiText`, `HindiPhrases`) are not listed here; they belong to the core tables.

### Left in English on purpose

- The NPU / CPU / SIMULATED pills (technical proof labels).
- A provisional date: the card only holds the English display of the value, so it cannot be written again from the stored text.
- The stored reason strings the screen passes to the view model ("set by the reporter", "cancelled alarm"): they are stored values.
- The recording clock (`formatClock`) is Latin digits; it lives in Chrome.kt.
